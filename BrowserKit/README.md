# BrowserKit

A collection of projects that are useful for building a browser, split into separate Swift packages:

- `Core` - Common, Shared, TabDataStore, WebEngine, JWTKit, ContentBlockingGenerator, ActionExtensionKit and TestKit
- `Components` - ComponentLibrary and SiteImageView
- `Redux` - Redux and ReduxTestKit
- `AppAttestKit` - AppAttestKit and AppAttestTestKit
- `FeatureKits/<Kit>` - one package per feature kit (ToolbarKit, MenuKit, OnboardingKit, UnifiedSearchKit, WebCompatReporterKit, SummarizeKit, LLMKit, MLPAKit, QuickAnswersKit)
