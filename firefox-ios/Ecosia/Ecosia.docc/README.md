# 🌳 Ecosia for iOS

Ecosia for iOS is an Ecosia-branded build of the Firefox iOS codebase. This DocC bundle provides a short orientation and links to focused how‑to and design pages for contributors.

Summary

Ecosia lives under firefox-ios/Ecosia and contains the Ecosia Framework (UI, assets, NTP) together with integration points into the upstream Firefox code. Use the Getting Started guide to set up a local environment. See Architecture for a short design overview and key paths.

- [Getting started](./GettingStarted.md) — dependencies, setup and common build commands
- [Architecture & design](./Architecture.md) — high‑level layout and New Tab Page (NTP) notes
- [Localization (L10N)](./Localization.md) — Transifex, pulling/pushing, and local checks
- [Contributing](./Contributing.md) — git hooks, commenting guidelines and linting
- [Release](./Release.md) — release notes and App Store upload guidance
- [Snapshot testing](./SnapshotTesting.md) — snapshot test workflow and quick commands
